Free tools to start building today
==================================

Jupyter Notebooks      prototype step by step, with live charts
                       -> a standard Python environment, on your laptop

Google Colab, Kaggle   train and fine-tune models in the cloud
                       -> some free GPUs and TPUs, competitions

Hugging Face           find and download open-source models
                       -> Whisper, Llama, Phi, GGUF for Ollama...

Roboflow               build computer vision datasets
                       -> free labelling, augmentation, YOLO exports

Streamlit              turn a Python script into a web app
                       -> free hosting on Community Cloud,
                          like tonight's dashboard
